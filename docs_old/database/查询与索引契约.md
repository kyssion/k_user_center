## 代码约束

- 任何参数、JSON Schema、协议字段和业务枚举先由代码校验；数据库错误不是常规输入校验流程。
- 不允许为了复用索引而省略 Tenant、Business Line、Owner、状态、过期时间、数据范围或软删除条件。
- 公共 ID、Token 摘要和唯一占用查询使用等值条件；Range 分区公开 ID 查询应尽量携带时间范围，否则会扫描多个分区索引。
- Worker 领取必须使用原子条件 UPDATE/CAS；SELECT 命中索引不表示已经获得任务所有权。
- 新增或改变高频查询时先更新本文件，再评审索引；禁止机械地为每个 `*_id` 创建单列索引。
- GIN 数组查询只用于反向影响分析，不证明数组中的逻辑引用有效；写入时仍需逐项校验策略版本、Owner、Scope 和状态。
- PostgreSQL 实跑阶段使用代表性数据量验证执行计划、分区裁剪、排序、GIN 选择性和写放大。
