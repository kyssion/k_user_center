## 9. 自动化测试

- [ ] 正向路径。
- [ ] 参数和 Schema 非法。
- [ ] 未认证、越权和数据范围越界。
- [ ] 跨租户/跨 Client/跨 Business Line。
- [ ] 非法状态转换。
- [ ] 并发与 CAS 冲突。
- [ ] 相同幂等键相同请求。
- [ ] 相同幂等键不同请求。
- [ ] 重放、过期和防枚举。
- [ ] Outbox/Audit/幂等任一失败时整体回滚。
- [ ] 数据库、缓存、消息、KMS/秘密存储故障注入。
- [ ] 敏感数据不会进入日志、事件或审计。
