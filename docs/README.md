# 文档导航

本目录区分规范性设计、实施契约、当前项目状态和机器生成证据。日常开发不需要顺序阅读全部文件，按下列入口定位即可。

## 推荐阅读顺序

1. [能力地图](./能力地图.md)：平台建设范围、能力编号、领域边界、分期与 Owner。
2. [建设与验收蓝图](./统一身份与访问平台建设与验收蓝图.md)：规范性需求、不变量、API/事件、安全 Profile 和验收门禁。
3. [数据库设计总纲](./数据库设计总纲.md)：目标数据模型、数据库职责、对象组织与验证规则。
4. [阶段 0 实施状态](./代码实施/阶段0实施状态.md)：当前允许开工范围、阶段 0 整改计划和阶段 1a 门禁。
5. [代码实施契约](./代码实施/代码实施索引.md)：命令、事务、权限、并发、幂等、事件和错误契约。
6. [架构决策](./架构决策/README.md)：影响信任边界、数据库完整性、审计和技术选型的 ADR 与决策台账。
7. [威胁模型](./安全/威胁模型.md)：平台资产、信任边界、主要攻击路径及验证要求。

## 权威来源与冲突处理

| 内容 | 权威来源 | 其他文档的作用 |
|---|---|---|
| 能力范围、优先级、启用触发 | `能力地图.md` | 蓝图和矩阵不得创建未登记能力 |
| MUST、不变量、协议、安全 Profile、SLO | `统一身份与访问平台建设与验收蓝图.md` | 代码规范只能展开，不能放宽 |
| 错误码与 Operation 原因码 | `代码实施/错误码注册表.csv` | Markdown 表由注册表语义生成或引用 |
| 状态机目录与 Owner | `代码实施/状态机注册表.csv` | 蓝图定义转换细节，命令规格卡绑定本次转换 |
| 数据库可执行对象 | `database/postgresql` SQL | 数据库 Markdown 和 generated 报告是导航与证据 |
| 命令事务、权限和并发 | 已评审命令规格卡 + 全局事务规范 | 领域命令规范是概要，不是完整编码输入 |
| 当前实现和验收覆盖 | `代码实施/实施追踪矩阵.csv` | 数据库覆盖索引不能替代正式矩阵 |
| 项目级技术决策 | `架构决策/*.md` 与 `决策台账.csv` | 会议纪要和默认配置不构成决策 |

出现冲突时先停止实现并修复权威来源及其生成投影，不允许由实现者自行选择较宽松版本。

## 按任务查阅

| 任务 | 入口 | 说明 |
|---|---|---|
| 修改能力范围或建设阶段 | [能力地图](./能力地图.md) | 保持 `CAP-*`、Phase 和 Owner 可追踪 |
| 修改规范性业务或安全规则 | [建设与验收蓝图](./统一身份与访问平台建设与验收蓝图.md) | 同步需求、不变量、API/事件和验收编号 |
| 修改表、字段、约束或索引 | [数据库实施导航](./database/README.md) | SQL 是可执行权威来源，生成报告不得手工修改 |
| 实现领域命令 | [领域命令规范](./代码实施/领域命令规范.md) | 同时遵守全局事务规范并填写命令规格卡 |
| 实施阶段 0 工程骨架 | [阶段 0 技术方案与工程结构](./代码实施/阶段0技术方案与工程结构.md) | 先批准目录、版本和程序集边界，再生成代码 |
| 判断能否进入业务开发 | [阶段 0 实施状态](./代码实施/阶段0实施状态.md) | 以当前门禁和证据为准 |
| 修改错误码或 Operation 原因 | [错误码注册表](./代码实施/错误码注册表.csv) | 同步生成或校验蓝图、SDK 与测试 |
| 修改状态字段或新增状态机 | [状态机注册表](./代码实施/状态机注册表.csv) | 同步蓝图转换、数据库字段和属性测试 |
| 修改信任边界或完整性策略 | [架构决策](./架构决策/README.md) | 新建或取代 ADR，不直接改结论文本 |

## 机器生成与按需证据

- `database/generated/`：数据字典、表/字段/索引清单和数据库对象检查报告。
- `database/需求编号与数据库持久化覆盖索引.md`：规范编号到数据库持久化边界的生成索引，不是正式实施矩阵。
- `database/逻辑关系与非数据库校验清单.md`：由 SQL Comment 生成的逻辑引用与孤儿检查清单。
- `代码实施/实施追踪矩阵.csv`：正式代码实施与验收矩阵，保持机器可解析。
- `代码实施/Validate-DocumentationContracts.ps1`：文档机器契约校验；修改错误、状态、查询或矩阵后必须执行。

机器生成文档用于评审、验证和追踪，不作为首次阅读入口。
