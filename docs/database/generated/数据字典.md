- 说明：旧系统迁移批次、检查点和统计；读取、转换、冲突处置和提交由 MIG 代码编排。

| 字段 | SQL 定义 | Comment |
|---|---|---|
| `id` | `uuid PRIMARY KEY` | 应用生成的迁移批次 UUIDv7。 |
| `system_id` | `uuid NOT NULL` | 逻辑引用 iam.legacy_systems.id。 |
| `batch_code` | `varchar(160) NOT NULL` | 旧系统内稳定批次代码。 |
| `operation_id` | `uuid NOT NULL` | 逻辑引用 iam.operations.id。 |
| `state` | `varchar(40) NOT NULL` | 批次状态。 |
| `source_checkpoint` | `jsonb NOT NULL DEFAULT '{}'::jsonb` | 源读取检查点；代码解释和推进。 |
| `total_count` | `bigint NOT NULL DEFAULT 0` | 发现或计划对象总数。 |
| `success_count` | `bigint NOT NULL DEFAULT 0` | 成功迁移数量。 |
| `conflict_count` | `bigint NOT NULL DEFAULT 0` | 需人工或规则处置冲突数量。 |
| `failure_count` | `bigint NOT NULL DEFAULT 0` | 失败数量。 |
| `result_summary` | `jsonb` | 可空；脱敏结果摘要。 |
| `started_at` | `timestamptz` | 可空；批次开始时间。 |
| `completed_at` | `timestamptz` | 可空；批次完成时间。 |
| `created_at` | `timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP` | 数据库插入时间。 |
| `updated_at` | `timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP` | 数据库更新时间；应用显式刷新。 |
| `row_version` | `bigint NOT NULL DEFAULT 0` | 乐观锁版本。 |

## iam.migration_items

- 来源：`140_legacy_migration.sql`
- 说明：迁移批次内逐对象状态和差异摘要；转换和冲突决策由 MIG 代码执行。

| 字段 | SQL 定义 | Comment |
|---|---|---|
| `id` | `uuid PRIMARY KEY` | 应用生成的迁移项 UUIDv7。 |
| `batch_id` | `uuid NOT NULL` | 逻辑引用 iam.migration_batches.id。 |
| `external_object_type` | `varchar(80) NOT NULL` | 旧对象类型。 |
| `external_object_id_digest` | `varchar(256) NOT NULL` | 旧对象 ID 安全摘要。 |
| `platform_object_type` | `varchar(80)` | 可空；平台对象类型。 |
| `platform_object_id` | `uuid` | 可空；平台对象逻辑 ID。 |
| `source_version` | `varchar(256)` | 可空；源对象版本。 |
| `state` | `varchar(40) NOT NULL` | 迁移项状态。 |
| `difference_summary` | `jsonb NOT NULL DEFAULT '{}'::jsonb` | 脱敏差异摘要。 |
| `result_code` | `varchar(100)` | 可空；稳定处理结果码。 |
| `attempt_count` | `integer NOT NULL DEFAULT 0` | 处理尝试次数。 |
| `next_attempt_at` | `timestamptz` | 可空；代码计算的下次重试时间。 |
| `created_at` | `timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP` | 数据库插入时间。 |
| `updated_at` | `timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP` | 数据库更新时间；应用显式刷新。 |
| `row_version` | `bigint NOT NULL DEFAULT 0` | 乐观锁版本。 |

## iam.migration_change_logs

- 来源：`140_legacy_migration.sql`
- 说明：切换期不可变增量变更日志；按 recorded_at 月度分区，顺序、幂等和冲突由 MIG 代码处理。
- 分区：`PARTITION BY RANGE (recorded_at)`

| 字段 | SQL 定义 | Comment |
|---|---|---|
| `id` | `uuid NOT NULL` | 应用生成的日志 UUIDv7。 |
| `system_id` | `uuid NOT NULL` | 逻辑引用 iam.legacy_systems.id。 |
| `external_object_type` | `varchar(80) NOT NULL` | 旧对象类型。 |
| `external_object_id_digest` | `varchar(256) NOT NULL` | 旧对象 ID 安全摘要。 |
| `sequence_no` | `bigint NOT NULL` | 同外部对象的正整数变更序号。 |
| `source_version` | `varchar(256) NOT NULL` | 源对象版本。 |
| `idempotency_key` | `varchar(200) NOT NULL` | 源变更幂等键；跨分区唯一性由 iam.idempotency_records 保证。 |
| `change_type` | `varchar(80) NOT NULL` | 变更类型。 |
| `payload_ciphertext` | `text` | 可空；确需保存时的源变更应用密文。 |
| `payload_digest` | `char(64) NOT NULL` | 规范化变更载荷 SHA-256 摘要。 |
| `state` | `varchar(40) NOT NULL` | 变更消费状态。 |
| `occurred_at` | `timestamptz NOT NULL` | 源变更实际发生时间。 |
| `recorded_at` | `timestamptz NOT NULL DEFAULT CURRENT_TIMESTAMP` | 数据库落库时间和月度分区键。 |
