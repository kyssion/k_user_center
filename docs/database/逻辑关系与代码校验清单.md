# 逻辑关系与代码校验清单

数据库不创建 Foreign Key。下表是代码写入前校验和孤儿扫描的契约；`required` 仅表示列非空要求，不代表目标可在任意状态下被引用。

## 统一校验

1. 目标记录存在且类型匹配。
2. Source 与 Target 的业务线、租户、组织和环境边界一致。
3. 目标状态允许建立关系，且未过期、撤销、冻结或匿名化。
4. Actor 对 Source 和 Target 均有权限；高风险关系满足保证等级、风险和审批。
5. 更新使用 Source/Target 的 `row_version` 或安全水位避免 TOCTOU。
6. 删除、匿名化和终态变更按 `delete_behavior` 执行，不做数据库级联。
