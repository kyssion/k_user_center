## 代码约束

- 不允许为了复用索引而省略 Tenant、Owner、状态或过期条件。
- 公共 ID、Token 摘要和唯一占用查询必须使用等值条件。
- Worker 领取必须使用原子状态/CAS 更新，索引命中不代表已获得任务所有权。
- 新增或改变高频查询时，先更新本文件，再评审索引；禁止机械为每个 `*_id` 建单列索引。
- PostgreSQL 实跑阶段使用代表性数据量验证执行计划、排序、分区裁剪和写放大。
