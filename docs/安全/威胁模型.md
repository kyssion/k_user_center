# 统一身份与访问平台威胁模型

> 状态：阶段 0 候选基线。每个进入迭代的命令必须把适用威胁绑定到命令规格卡和自动化负向测试；本文不替代具体协议组件的安全评审。

## 资产与信任边界

关键资产包括 Global User、Identifier、认证材料、登录事务、Session、Grant、Token、授权策略、密钥、Consent、审计证据和安全水位。信任边界沿用建设蓝图 §2.3：协议数据面、凭证域、会话撤销域、授权域、风险域、控制面、隐私编排域、事件与审计域。

业务应用、浏览器、移动端、管理员终端、上游 IdP、短信/邮件供应商、消息系统和远端审计域均视为独立信任域；不可枚举 ID、前端隐藏按钮和数据库技术角色不构成业务授权。

## 威胁与最低控制

| ID | 威胁 | 主要控制 | 必须验证 |
|---|---|---|---|
| `THR-001` | 账号枚举与状态探测 | 错误收敛、时延收敛、限流、防枚举字段策略 | `AT-AUTH-001`、预认证错误差异测试 |
| `THR-002` | 标识回收与账号接管 | 墓碑、隔离期、双侧验证、SIM swap/域名风险 | `AT-ID-004/009` |
| `THR-003` | 授权码、Challenge、Refresh Token 重放 | 摘要存储、上下文绑定、原子单次消费、Family 撤销 | `AT-AUTH-003/009/010`、`AT-SESSION-001/007/008` |
| `THR-004` | OAuth mix-up、Token substitution 与算法降级 | issuer/audience/nonce/PKCE/typ 校验、算法 Allowlist、组件一致性测试 | `AT-AUTH-002/008/012`、协议攻击套件 |
| `THR-005` | 跨租户、跨 Client 与跨数据范围访问 | 可信上下文、代码侧 PEP、查询前过滤、缓存键绑定 | `AT-TENANT-001`、`AT-AUTHZ-004/010` |
| `THR-006` | TOCTOU、并发覆盖和重复副作用 | expected version、行锁顺序、幂等摘要、提交点重决策 | CAS、并发和故障注入测试 |
| `THR-007` | 控制面越权、恶意配置和密钥失陷 | 双人复核、职责分离、不可变版本、灰度、KMS/HSM、紧急撤销 | `AT-CTRL-*`、`AT-KEY-*` |
| `THR-008` | Webhook SSRF、签名绕过和重放 | Endpoint 所有权、出站 Allowlist、DNS 重绑定防护、签名与时间窗 | `AT-EVENT-001/002/003` |
| `THR-009` | PII、凭证或 Token 泄漏到日志事件审计 | 字段白名单、摘要/密文、短期秘密句柄、持续扫描 | `AT-SEC-001`、消息秘密负向测试 |
| `THR-010` | 审计绕过或篡改 | 本地审计与权威事实原子提交、仅追加权限、远端幂等投影 | `AT-AUDIT-001`、审计故障注入 |
| `THR-011` | 撤销传播延迟与陈旧缓存放行 | security/consent epoch、watermark、Profile 分级失败关闭 | `AT-SESSION-002/009`、`SLO-REVOKE-*` |
| `THR-012` | 迁移双主、回滚丢数据和旧凭证复活 | 单一权威写入方、不可变变更日志、反向同步、对账 | `AT-MIG-001` 至 `AT-MIG-007` |

## 使用要求

- 命令规格卡填写适用 `THR-*`、攻击前置条件、控制点和自动化证据。
- 协议组件、KMS/HSM、短信供应商和外部 IdP 选型必须补充供应链、依赖失陷和运行权限分析。
- 新增信任域、外部数据接收方、认证方式或不可逆流程时必须更新本文和追踪矩阵。
