# ADR-0002：审计事实与远端审计投递

- 状态：`ACCEPTED`
- 决策域：事务、审计、防篡改与故障语义

## 决策

1. `iam.audit_events` 是本地权威审计事实，不是可覆盖的日志，也不是仅用于投递的临时队列。
2. 安全敏感命令在同一数据库事务中提交：领域权威事实、`audit_events`、领域 Outbox、审计投递 Outbox 和幂等结果。
3. 审计投递复用 `iam.outbox_events`，事件类型为稳定注册的审计投递类型，Payload 只包含远端投影所需的最小字段或本地 `audit_event_id`；禁止复制密码、验证码、完整 Token、私钥或未登记 PII。
4. 远端独立审计域按 `audit_event_id` 幂等消费，是查询、取证、隔离存储和长期保留投影，不参与业务事务的同步双写。
5. 本地 `audit_events` 或对应审计投递 Outbox 写入失败时，高风险命令失败关闭。
6. 远端短时不可用时积压 Outbox；超过版本化依赖失败策略登记的时间或积压阈值后，停止受影响的高风险写入并告警。普通只读是否降级由 Security Profile 决定。

## 结果

- 不新增第二套 Audit 状态机或 `audit_outbox` 表。
- `audit_events` 的不可变和最小字段规则由 OBS 领域持有。
- Outbox 的领取、重试、死信和对账由 EVENT 领域持有。
- 部署验证必须同时证明本地仅追加权限和远端安全域隔离。
