# 架构决策导航

本目录记录会改变信任边界、数据完整性、协议选型、事务语义或不可逆结果的项目级决策。会议纪要不能替代 ADR。

## 状态

- `PROPOSED`：候选方案，不能作为生产实现依据。
- `PROVISIONAL`：阶段 0 暂定基线，必须完成登记的验证和批准后才能冻结。
- `ACCEPTED`：已经批准，可作为实现约束。
- `SUPERSEDED`：被后续 ADR 取代，保留历史但不得继续引用为当前决策。
- `REJECTED`：评审后不采用。
